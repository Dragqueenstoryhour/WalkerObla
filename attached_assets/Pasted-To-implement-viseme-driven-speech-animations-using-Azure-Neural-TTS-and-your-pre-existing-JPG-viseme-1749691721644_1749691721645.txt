Set Up Azure Speech SDK and Project Environment:
Tools/Libraries: Use the Azure Speech SDK for JavaScript (azure-cognitiveservices-speech-sdk) to handle text-to-speech and viseme events. Include it via CDN or npm (npm install microsoft-cognitiveservices-speech-sdk). Use a web framework like React for the UI, with Tailwind CSS for styling, and a simple HTML canvas or DOM element for rendering JPGs.
Code Requirements: Configure the Speech SDK with your Azure subscription key and region. Subscribe to the VisemeReceived event to capture viseme IDs and audio offsets. Ensure your project has access to the viseme images in client/src/assets/Visemes.
Details: Initialize the Speech SDK with SpeechConfig.fromSubscription("YourSubscriptionKey", "YourRegion") and AudioConfig.fromDefaultSpeakerOutput(). Store viseme events in an array for synchronization.
Prepare SSML Input for Viseme Output:
Tools/Libraries: Use SSML (Speech Synthesis Markup Language) to request viseme IDs (no SVG required since you’re using JPGs). A text editor or IDE like VS Code is sufficient for crafting SSML.
Code Requirements: Create an SSML string specifying the voice (e.g., en-US-JennyNeural) and include the <mstts:viseme type="VisemeID"/> element to get viseme IDs and audio offsets. Example:

Synchronize Viseme Images with Audio:
Tools/Libraries: Use JavaScript’s setTimeout or requestAnimationFrame for timing, and the HTML <img> element or a canvas for rendering viseme JPGs. Preload images to avoid loading delays.
Code Requirements: Map viseme IDs to your JPG files (e.g., viseme ID 0 → viseme-id-0.jpg). On each VisemeReceived event, extract the viseme ID and audio offset (in ticks, convert to milliseconds by dividing by 10,000).
